# v0.6 地图探索体验设计

日期：2026-10-08

状态：功能方向已确认；本设计稿待用户 review，尚未进入功能实现。

目标版本：`hexo-post-map` v0.6.0

基线：v0.5.0，提交 `2fbd9b14ebf7a926243e7dfb3f5172bbf6522372`

## 1. 已确认的目的与范围

插件继续以开源、免费核心功能为主，不强制购买新的第三方套餐，不新增地图引擎、导航、地理编码或后端服务。已有高德服务的使用条件和额度独立于插件自身的许可证，不承诺第三方服务无限免费。

0.6 聚焦全国文章地图的三项体验：

1. 从地图进入文章后返回，恢复地图位置、缩放等级、文章面板和列表滚动位置。
2. 生成当前地图视野或单篇文章预览的分享链接。
3. 提供可选的“随机一站”，帮助读者发现带定位的旧文章。

目标用户包括插件安装者、普通博客读者以及使用手机或键盘访问地图的读者。成功标准不是增加按钮数量，而是在传统静态站点与常规 PJAX 导航中保持连贯、可预测的探索体验。

本版不做筛选、其他地图引擎、本地标注工具、故事模式、轨迹编辑器、导航规划、离线地图、3D 地形、账户收藏、访问分析或分享短链服务。也不重新实现 v0.5 的轨迹回放。

## 2. 当前结构与兼容边界

- `src/browser/overview/index.ts` 负责读取 `posts.json`、加载高德和打开文章面板。
- `src/browser/providers/amap-overview.ts` 负责聚合、图片标记、地图生命周期和聚合点击行为。
- `src/browser/overview/panel.ts` 负责非模态面板、滚动容器、延迟图片和关闭后的焦点恢复。
- 共享 runtime 负责 PJAX 根节点的发现与销毁；BFCache 中的存活 controller 不会被销毁。
- 文章引用使用已发布的 `OverviewPost.url`，不是人工维护的地理身份，也不是数组下标。

本版保持 Front Matter、GCJ-02 地点、WGS84 轨迹、`posts.json` version 1、固定浏览器资源路由及 `window.HexoPostMap` API version 1 不变。详情地图不承担本版状态恢复或分享控制。新增代码只进入 overview 功能包；`runtime.js` 继续不包含地图提供商和探索业务代码，维持既有 8 KiB 压缩体积限制。

## 3. 状态管理方案选择

推荐方案是“同一文档内的有界内存快照 + 当前标签页 `sessionStorage`”，显式分享链接作为首次进入的高优先级输入。

另两个方案不在本版采用：

- 直接写入 `history.state`：可以跟随历史条目，但会与主题和 PJAX 路由器共享状态所有权。
- 使用 `localStorage`：会跨会话、跨标签页保留探索记录，扩大隐私与过期状态的处理范围。

插件不调用 `history.pushState`、`history.replaceState`，不改写地址栏、主题的 history state 或滚动恢复策略。0.6 的“恢复”是返回该地图时恢复最近一次探索快照，不保证逐条重放同一路由的每个历史条目，也不保证主题自己的页面滚动位置。

## 4. 站点配置与默认值

在站点 `_config.yml` 中增加可选配置：

```yaml
post_map:
  overview:
    exploration:
      restore: true
      share: true
      random: false
```

这里是已有 `post_map` 配置的局部示例；完整配置仍须满足现有高德凭据和安全模式要求。

- `restore` 默认 `true`：允许读取与保存本插件的会话快照。
- `share` 默认 `true`：显示分享按钮，并允许解析本插件的分享参数。
- `random` 默认 `false`：保持默认界面简洁，由作者主动启用。
- 三项只接受布尔值；未知字段、数组、`null` 等按现有严格配置规则报错，错误只标识字段，不输出凭据。
- `restore: false` 时不读取快照用于恢复、不记录新的浏览状态，并仅清除当前地图作用域的插件快照；允许读取插件自己的缓存索引以定位该记录，但不得调用 `sessionStorage.clear()`。
- `share: false` 时不显示分享 UI，也不解析分享参数；状态恢复仍独立工作。
- 三项全关闭时，保留 v0.5 的全国地图交互。
- 缓存中的旧 HTML 若没有新增探索配置或地图页面 URL，新功能按关闭处理，不导致原有地图初始化失败。

生成器向 overview 根节点的惰性 JSON 配置增加探索开关和 root-aware 的 `overviewUrl`。该 URL 在构建时由既有 Hexo 路径规范化逻辑生成，不通过删除 `posts.json` 字符串来猜测页面地址。详情配置与 `posts.json` 不增加这些字段。

## 5. 浏览状态恢复

### 5.1 保存内容与作用域

快照只包含以下允许字段：

- 协议版本 `1` 与保存时间。
- 地图中心点 `[longitude, latitude]` 和缩放等级。
- 面板模式：关闭、全部文章、单篇文章、聚合文章组。
- 当前面板使用的文章 URL 引用。
- 列表滚动锚点：首个可见文章 URL 与相对偏移；可保留有界的像素位置作为备用值。

不得持久化文章正文、图片、完整 `posts.json`、高德 Key、安全密钥、代理配置、GPX/GeoJSON 内容、轨迹路径、私有源文件名或高德对象。

作用域由当前 origin、规范化的 `overviewUrl` 与数据 URL 的 origin/pathname 共同确定，保留端口和站点根路径。`/map/`、`/blog/map/` 与自定义地图路由互不覆盖。快照不得采用包含凭据、查询串或片段的 URL 作为存储标识。

会话缓存使用一个带版本的插件专属命名空间；最多保存 16 个作用域，单份序列化快照最多 16 KiB，超过两小时的快照失效。使用最近保存时间淘汰，不读取或修改其他功能的存储数据。存储读取、解析、写入及淘汰全部是 best-effort；被禁止、额度不足或格式错误时，不影响地图和文章列表。

### 5.2 数据验证与过期引用

即使快照来自当前 origin，也按不可信输入验证：只接受允许字段、有限数值、合法经纬度、有界字符串和数组。缩放值限制到当前 `cluster.max_zoom` 允许范围；非法中心点不得传给高德。

文章引用只能匹配本次已验证数据集中的已知 URL，不从快照动态请求文章或远程资源。重复 URL 产生的歧义不能静默选中另一篇文章。已删除或歧义的单篇引用关闭面板；聚合组缺少任何成员时也关闭面板，不恢复成错误的部分列表。地图视野仍可恢复。

聚合组最多存储 128 个引用。组引用超出数量或快照总大小限制时，仅保留地图视野并关闭面板，不截断后冒充完整文章组。全部文章模式只保存模式和滚动信息，不保存全站 URL 列表。

锚点文章失效时，使用可用的有界像素位置；滚动位置始终限制到当前滚动容器范围。尺寸变化后优先恢复锚点，不恢复页面整体滚动，也不强制聚焦关闭按钮。

### 5.3 恢复优先级

对新的 overview controller，优先级为：

1. 当前地图页面上有效的显式分享参数。
2. 当前作用域中未过期的内存快照。
3. 当前作用域中未过期的会话快照。
4. v0.5 的默认文章范围视图，面板关闭。

分享参数只有在当前 URL 对应构建时的地图页面路由时才适用。比较时只把该路由末尾的字面 `index.html` 视为目录路径的别名，不解码百分号分隔符、不猜测其他路径。嵌入普通页面的 overview 根节点不得消费该普通页面的参数。读取位置在数据和 provider 代码加载完成、开始挂载地图之前确认，并再次检查根节点仍然有效，避免处理已离开的 PJAX 页面。

存活的 BFCache controller 和重复 `refresh()` 不重新执行上述恢复，避免覆盖读者当前操作。存储不可用时，文档内 PJAX 返回仍可通过内存快照恢复；跨完整文档导航则允许降级为默认视图。

### 5.4 保存与生命周期

- 地图的 `moveend` / `zoomend`、面板模式变化、列表滚动会更新候选快照。
- 会话写入使用 200 ms 合并窗口；不在每个滚轮、触摸或动画帧中序列化数据。
- 离开、根节点销毁时，在销毁高德对象之前 best-effort 保存最后有效快照。
- 面板因用户关闭而消失，应保存为关闭；因 controller 销毁或替换而消失，不得覆盖待恢复的打开状态。
- 显式 `restore: false`、失败的半初始化或旧 controller 的迟到回调不保存快照。
- BFCache 的 `pagehide` 可刷新快照，但不销毁 controller，也不增加 `unload` / `beforeunload` 监听器。
- 所有延迟写入、动画帧、地图事件与 DOM 监听器在 controller 销毁时取消；迟到回调不得覆盖新 controller 的快照。

多个 live overview 根节点保持 controller 隔离。仅当它们明确使用相同地图页面和数据作用域时共享返回快照；不使用全局“当前文章”变量。

## 6. 分享链接

### 6.1 v1 链接格式

分享链接以构建时的地图页面路径和当前浏览 origin 为基础，支持 `/`、`/blog/` 和自定义 `overview.path`。不把本地调试地址替换为配置中未核验的生产域名。

保留以下四个参数名作为公开的 v1 分享格式：

- `hpm_v=1`
- `hpm_center=longitude,latitude`
- `hpm_zoom=zoom`
- `hpm_post=...`：可选，用 `URLSearchParams` 编码单篇文章的公开 URL 引用。

示例：

```text
/blog/map/?hpm_v=1&hpm_center=121.49%2C31.24&hpm_zoom=11&hpm_post=%2Fblog%2Fposts%2Fshanghai%2F
```

中心点最多输出六位小数，缩放最多两位小数；分享格式用于视图，不修改文章坐标精度。单篇引用只在当前面板确实对应一篇且该引用唯一时附带。全部文章和聚合面板分享视野，不携带整组文章、阅读进度或滚动位置。

输出链接只包含规定的插件参数，不复制当前页面的任意查询参数或片段。不得包含 Key、安全密钥、代理地址、源轨迹、图片 URL 或文章正文。总链接上限 4096 个字符；文章引用无法安全表示或超长时，降级为纯地图视野分享。

### 6.2 参数安全与应用行为

重复的插件参数、未知协议版本、超长输入、非有限数值和非法中心点忽略，不让地图整体失败。未知的 `hpm_` 参数使该分享载荷失效；非插件参数不作为业务输入。

一个有效视野中的未知、已删除或歧义 `hpm_post` 只降级为视野分享。有效文章引用打开其现有单篇面板，不自动跳转文章，不自动播放轨迹，也不将输入插入 HTML。输入引用只能从当前数据集查找，绝不能作为独立 `href` 或 fetch 目标。

分享 URL 是首次挂载的输入；插件不持续同步地址栏，也不接管 `popstate`。通过主题的 PJAX 返回时由新 controller 恢复，保持常规 light-DOM 自动兼容边界；仅改 URL、不替换或通知内容的非标准路由方式不新增自动兼容承诺。

### 6.3 分享操作与降级

地图加载成功后显示“分享地图”按钮。点击时读取当前有效视图与单篇选择；地图仍初始化或已失败时不允许生成不完整链接。

仅在用户点击触发的操作中调用 `navigator.clipboard.writeText()`。不要求浏览器权限始终可用，不使用自动复制或旧的 `execCommand`。成功通过简短的 `aria-live` 文本反馈“链接已复制”。

剪贴板 API 不存在、环境不允许或用户拒绝时，在插件根节点内显示带标签的只读链接输入框，便于手动复制；提供关闭按钮和 Escape 关闭，关闭后回到分享按钮。该降级不是高德 InfoWindow，不包含原始浏览器错误，也不导致地图失败。已提交的系统剪贴板操作不能保证取消，但 controller 销毁后的 Promise 回调不得创建复制框或更新状态文本。

## 7. 随机一站

`random: true` 时，地图加载成功后增加“随机一站”按钮。选择完全基于已经加载的公开 `posts.json`，不调用导航、地理编码、定位或推荐服务，不请求文章正文，不增加统计上报。

候选是拥有安全、非空且唯一 URL 的当前文章。多篇候选时，排除当前单篇预览；当前没有单篇预览时排除本 controller 上一次随机选中的文章，以避免立即重复。剩余候选等概率选择。只有一篇时可预览该篇；没有候选时隐藏按钮，不调用随机函数或高德视图操作。

点击后把地图视野移动到该文章代表点并打开现有单篇面板。目标缩放为 `min(max_zoom, max(current_zoom, 11))`；不随机偏移坐标，不移除聚合，也不自动导航到文章。读者仍通过卡片链接进入文章。

仅用户触发的选择可以聚焦新面板。尊重减少动态效果设置，不播放轨迹、不自动轮播。连续点击和根节点销毁时只允许当前操作生效，不让旧视图回调重新打开已关闭的面板。

## 8. 内部接口与责任划分

- 新增 overview 专用的纯状态模块：快照校验、作用域、缓存边界、分享解析与生成。纯函数可注入时间与存储适配，便于确定性测试。
- 增加探索 controller：负责开关、恢复优先级、保存节流、分享 UI 和随机选择，与地图 provider、文章面板组合；不得成为包含 SDK、DOM、序列化和存储细节的单一大文件。
- provider 增加内部 overview 视图能力：读取视图、应用已验证视图、定位已验证文章，及视图结束变化回调。所有业务输入在调用 provider 前验证。
- 高德 overview 的恢复视图优先于初始全站范围 fitting，避免先显示默认视图再跳转；SDK 的其他聚合和同坐标文章行为保持不变。
- 面板增加内部快照/恢复能力与“自动恢复不抢焦点”的选项。用户关闭、面板替换和 controller 销毁的原因必须可区分。
- 对缺少新能力的旧内部测试替身或缓存配置，禁用探索操作而保留普通地图；provider 接口仍不是公开第三方扩展 API。
- SSR 新配置、toolbar 与其必要状态纳入 overview `isCurrent()` 检查，DOM 被主题替换后能够完整清理并重新挂载。

不得改变 Hexo generator 的轨迹隐私保证、源文件防泄漏逻辑、固定 `posts.json` 名称或公开生命周期版本。README 同时说明 sessionStorage 只是浏览器端会话数据，并不是保密边界或用户账户收藏。

## 9. 性能、响应式与可访问性

- 新 toolbar 与“全部文章”布局统一；默认只多一个分享按钮。手机上不得遮挡地图署名、已有定位图片或文章抽屉的关闭按钮。
- 键盘可操作分享、复制降级、随机按钮、面板和卡片链接；所有控制保留明确标签和至少 44 px 的交互区域。
- 自动恢复不触发页面滚动，不抢夺其他页面控件的焦点；用户触发的面板打开仍保留既有关闭/焦点规则。
- 分享与随机功能不可用时不导致全部文章按钮不可用。存储或复制异常只降级对应功能。
- 滚动时不重建面板、不重新创建聚合、不进行每像素全列表扫描，不反复测量全部卡片或重新请求所有缩略图。
- 读写快照只处理受限的简单数据。随机操作复用当前文章索引；普通页面、详情页面不会因此请求 overview 资源或 `posts.json`。
- 维持既有浅色、深色、强制颜色、减少动态效果及 CSS 公共变量边界；没有 JavaScript 或 SDK 失败时的静态文章列表继续可用。

## 10. 验证与交付要求

### 10.1 单元与组件测试

覆盖严格配置和默认值、旧 HTML、三开关全关、数值边界、重复 URL、过期/损坏/超额快照、不可用存储、不同根路径和作用域隔离。验证真实 serializer 从不包含配置凭据、图片、正文或轨迹数据。

覆盖恢复优先级、面板滚动锚点、用户关闭与销毁的区别、自动恢复不抢焦点、写入合并、取消任务以及旧 controller 无权覆盖新快照。分享解析覆盖重复键、中文与百分号、恶意 scheme、未知参数/版本、删除文章和长度限制；绝不将外部参数直接变成导航或网络请求。

随机测试注入确定性 RNG，覆盖空/单篇/多篇、重复引用、立即重复排除、减少动态效果、代表点保持原值，以及选择不会自动导航。

### 10.2 Chromium 与生命周期

在桌面和移动尺寸验证：

- 地图缩放/移动、打开全部文章、滚动、进入文章、浏览器返回的状态恢复。
- 常规 PJAX 地图 → 文章 → 地图，重复 refresh、根节点替换和资源请求去重。
- BFCache 恢复保留存活状态，不重复打开面板或初始化 SDK。
- 在初始化、复制 Promise 或视图变化期间移除根节点，迟到结果不得更新新 DOM 或快照。
- 新标签页打开分享链接，显式视野和单篇预览生效；不受接收者旧快照覆盖。
- 剪贴板成功、拒绝、不可用环境和手动复制降级。
- 30 篇及更大合成列表的边界滚动、缩略图延迟加载、toolbar、署名与焦点行为。
- snapshot/share 不触发正文或轨迹请求，普通页面仍保持 provider-free。
