# Cactus minimal fixture

Reduced from the MIT-licensed [hexo-theme-cactus](https://github.com/probberechts/hexo-theme-cactus)
3.0.0 layout, page and post templates. It preserves Cactus's `post` / `content` wrappers,
`page.content` rendering and outer layout. Optional theme helpers, CSS, navigation
configuration and scripts are deliberately omitted. This fixture verifies the
standard theme content contract; it is not a full Cactus visual regression test.
The original license and copyright notices are included in `LICENSE`.
